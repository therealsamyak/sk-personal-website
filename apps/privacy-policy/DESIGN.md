# Policy page design

Use one readable document with a warm neutral background and system fonts.

- Colors: background #f7f6f2, text #252620, muted #595b50, accent #285b46, border #d9dbd2.
- Dark colors: background #171a17, text #eeeeea, muted #b9beb5, accent #a5d6b9, border #3b423b.
- Typography: system sans-serif, 18px body, 1.7 line height, 44px title, 22px section headings.
- Layout: 720px reading width, 24px mobile gutters, 64px desktop top spacing.
- Primitives: document header, sections, underlined links, subtle section borders.
- States: visible keyboard focus, underlined hover links, no motion or controls.
- Responsive behavior: fluid column; title reduces to 34px on small screens.
- Accessibility: semantic main and headings, skip link, native text zoom, light and dark themes.

Use inline CSS and the Umami tracker only. No framework, fonts, images, or build step.
